# SubFree

**Kostenlose Subdomains für persönliche Projekte und Entwickler.**

SubFree ist ein unabhängiges Community-Projekt im Aufbau. Ziel ist es, ausgewählten Nutzern kostenlose Subdomains für persönliche Websites, Portfolios, Lernprojekte und nicht-kommerzielle Softwareprojekte bereitzustellen.

> **Status: Konzept / Frontend-Prototyp.** Es gibt derzeit noch keine automatische Registrierung, DNS-Verwaltung oder bestätigte Domainfreigabe. Eine Anfrage ist keine Zusage und reserviert keinen Namen.

## Geplante Funktionen

- Öffentliche Projekt- und Informationsseite
- Formular für Subdomain-Anfragen
- Manuelle Prüfung der Anfragen
- Spätere DNS-Einrichtung und Verwaltung
- Später ein Nutzerbereich mit Statusanzeige

## Aktueller Stand

Die Website ist eine statische HTML-, CSS- und JavaScript-Seite und kann über GitHub Pages veröffentlicht werden. Das Anfrageformular öffnet eine vorbereitete E-Mail. Es speichert keine Anfragen auf einem Server und verschickt sie nicht automatisch.

Die aktuell im Frontend gezeigte Beispiel-Endung `admin-coding.is-a.dev` ist **nicht als verfügbar oder für die Weitergabe freigegeben bestätigt**. Vor einem öffentlichen Start müssen die Regeln des Domainanbieters geprüft und die Nutzung ausdrücklich erlaubt sein.

## Lokal testen

Öffne `index.html` in einem Browser. Für die Veröffentlichung kann GitHub Pages in den Repository-Einstellungen aktiviert werden.

## Sicherheit und Missbrauchsschutz

SubFree soll nicht für Phishing, Malware, Spam, Betrug oder rechtswidrige Inhalte verwendet werden. Eine spätere Vergabe benötigt klare Nutzungsbedingungen, einen Abuse-Kontakt, eine Möglichkeit zur Sperrung missbräuchlicher Subdomains und eine sichere DNS-Verwaltung.

## Lizenz

Noch keine Lizenz festgelegt. Bis zur Ergänzung einer Lizenz gelten die üblichen urheberrechtlichen Regeln.
