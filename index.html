DIE FUNKTIONEN

Alles an einem Ort verwalten.

SubFree soll die Verwaltung kleiner Webprojekte einfach halten. Du brauchst dafür kein GitHub-Konto-Dashboard und musst keine Dateien direkt im Repository bearbeiten.

01

Eigener Projektname

Reserviere einen freien Namen und erhalte eine feste Projektadresse unter der SubFree-Domain.

02

Dateien verwalten

Bearbeite deine HTML-Startseite direkt im SubFree-Editor. CSS, JavaScript und weitere Dateien können über Dateipfade ergänzt werden.

03

Weiterleitungen

Erstelle statt einer Website auch eine HTTPS-Weiterleitung auf ein bestehendes Projekt.

04

Eigener Zugangscode

Kein Benutzerkonto. Ein einmalig angezeigter Zugangscode schützt die Verwaltung deines Projekts.

DER ABLAUF

In wenigen Schritten online.

01

Angaben eintragen

Projektname, GitHub-Benutzername und Kontakt-E-Mail angeben.

02

Code sicher speichern

SubFree erstellt einen persönlichen Zugangscode. Bewahre ihn auf, denn er wird nicht erneut angezeigt.

03

Projekt verwalten

Mit dem Code kannst du deine Dateien im Dashboard bearbeiten und veröffentlichen.
